
# Synchronized Lyrics

This directory contains synchronized LRC lyrics.

## Example

[ti:Example Track]
[ar:Example Artist]
[00:00.00]First line
[00:04.50]Second line
[00:08.20]Third line
[00:12.00]Fourth line

## Requirements

- UTF-8 encoding.
- LRC timestamps.
- One timestamp per synchronized line.
- Use the same filename as the corresponding track.

Example:

tracks/example-track.mp3
lyrics/example-track.lrc

Register the lyrics path in config.json.
