
# Album Covers

This directory contains album cover images.

Supported formats:
- PNG
- JPG
- JPEG
- WEBP

Recommended image dimensions:
- 512x512
- 600x600
- 1000x1000

Use the same filename as the corresponding track.

Example:

tracks/example-track.mp3
covers/example-track.png

Register the cover path in config.json.
